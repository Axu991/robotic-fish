# 机器鱼固件 (ESP-IDF + FreeRTOS)

基于 **ESP32-S3** 和 **ESP-IDF v5.5.3** 重构的机器鱼实时控制系统。

---

## 主要特性

- **硬实时控制**：核心控制任务以 **50Hz (20ms)** 周期锁步运行，保证 CPG 计算与舵机指令同步。
- **多模式运动**：
  - **CPG（中枢模式发生器）**：生成节律性摆动，支持开环与 **AHC（主动航向闭环）** 控制。
  - **UDP 直通模式**：接收上位机下发的关节角度，实现遥操作。
  - **轨迹回放模式**：预置动作序列，一键触发。
- **传感器融合**：
  - IMU：姿态角（Roll/Pitch/Yaw）、加速度、角速度
  - ADC：电池电压监测
  - 舵机反馈：实时位置、电流、温度
- **通信协议**：
  - **CRSF**：遥控器链路，支持 10 通道解析
  - **UDP**：上下行数据交互，实时上传状态
  - **CAN (TWAI)**：驱动 3 个舵机，带总线自动恢复机制
- **OTA 升级**：预留接口，支持无线固件更新
- **模块化设计**：驱动层、协议层、应用层分离，便于扩展和维护

---

## 硬件引脚定义

| 外设              | 功能说明         | ESP32-S3 引脚          |
|-------------------|------------------|------------------------|
| **LED**           | 状态指示灯       | GPIO17                 |
| **ADC**           | 电池电压监测     | GPIO16                 |
| **CAN (TWAI)**    | 舵机控制总线     | TX: GPIO4, RX: GPIO5   |
| **IMU (UART1)**   | 姿态传感器       | TX: GPIO6, RX: GPIO7   |
| **CRSF (UART2)**  | 遥控器接收       | TX: GPIO37, RX: GPIO2  |
| **USB 串口**      | 日志输出/烧录    | 内置 USB-Serial-JTAG   |
